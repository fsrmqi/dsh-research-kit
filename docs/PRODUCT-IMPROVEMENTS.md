# 性能、体验与功能优化

本轮保留原有安全与一致性修复，并完成以下功能。首次打开进入项目首页；已有分区偏好仍保留。

## 综述与恢复运行

在项目首页选择「做文献综述」，填写目标和筛选标准。可以从证据库导入 BibTeX／RIS，或把数据库查询返回的来源保存到当前课题。逐条纳入、排除或待定，排除时填写理由。前往 Claim 审阅，将论断关联到来源，填写支持／反驳立场、出处位置、评估人和理由。

换会话后，选择同一课题，在项目首页恢复原运行。继续研究草稿带原运行 ID，打开草稿后由研究者发送。证据库里的「导出当前项目综述与审核记录」生成 JSON，其中每条论断的 `links[].evidenceId` 对应候选表里的 `id`。包内同时提供筛选计数、排除理由和纳入文献的 BibTeX。导出需要访问文件论断台账并显示未确认及来源缺失状态。

## 项目与研究流程

- 首页提供综述、审稿、结论验证和继续上次工作流入口，汇总研究问题、材料提醒、待核验 Claim、未核验证据、待确认阶段与最近产出。
- 首页、证据库、Claim 审阅和独立图谱无需下载 PromptKit。方法工坊、灵感资产、迁移与草稿增强器在实际使用时加载。查看回答依据使用本地提取器，保存灵感资产时再加载 PromptKit。
- 分区职责说明可折叠。运行活动支持键盘展开；请求失败保留已有数据并展示重试错误。发送提示词仅记录发送事实，不代表完成研究执行。
- Claim 审阅可主动读取最近助手回答，先核对、提取、预览并勾选候选；载入段落限 12000 字，中断或截断会明确提示，不自动保存完整回答。

## 自动科研辅助与回答依据

输入框开关作用于当前会话。发送前可采用短版科研步骤，回答完成后可逐条查看结论、原文定位和缺少的材料。确认保存时，仅为所选结论建立明确的来源关联。图谱展示原文位置、论文链接和核验状态。真实桌面任务与隔离课题回归记录见[验收手册](MANUAL-QA.md#逐条原文追溯复测)。

## 搜索与图谱

在 Claim 审阅卡片打开「查看证据关系」，可按支持、反驳、证据不足和待评估回查当前论断的来源。页面显示已记录的原文位置、逐条评估人和来源核验状态，支持打开原文链接。收起关系后可在同一卡片继续审阅。无关联的论断直接提示补充来源；项目图谱仍保留零关系概览。


目录搜索预计算字段并按名称、标签、描述、类目、模板正文加权排序；同分结果稳定，展示匹配原因与高亮。支持综述、RNA-seq、GWAS 等中英文别名，类型计数随当前查询变化。图谱通过 URL／标识符索引取并集，并预计算数据库名称，避免对每条证据扫描全部来源；Claim 审核状态与每条证据关系的支持／反驳立场分开显示。零关系图不再把每个节点铺成网格：默认只绘制有关系的内容，未关联证据只汇总计数并可显式展开，避免「192 个节点 0 条关系」的卡片墙。

## 大证据库与可恢复操作

IndexedDB 升级至版本 7，新增时间与 ID 组合索引。证据库每页 50 条，游标处理同时间戳；选择在翻页或变更搜索、筛选条件后保留，切换课题时清空。摘要统计与条件搜索仍可能遍历完整范围，但不把完整范围渲染成卡片。导出与完整范围 Agent 判断主动读取完整范围，不受当前页限制。当前页质量提示仅覆盖当前页。

待筛选队列排除已经纳入或排除的证据，保留未处理及待定项。Agent 分批判断支持取消和继续未完成条目，不覆盖运行中被人工改变的数据。文件同步优先展示本地数据；失败可重试，重试会更新已存在的旧文件记录，非法来源记录显示忽略计数。上传按课题及数量／体积分批。同步接口仍使用完整文件列表，不能将分页渲染等同于端到端增量网络同步。

## Claim 的统一审核来源

文件 Claim 台账是审核状态的权威来源，IndexedDB 为离线与迁移投影。旧浏览器 Claim 按稳定 ID 幂等迁移为待核验草稿；保留研究问题、证据关系与立场，不把旧本地状态升级为人工确认。同 ID 已有文件记录绝不覆盖。台账分页读取超过 200 条的论断，页面每页显示 50 条；旧 MCP 列表工具保持原有最多 200 条的契约。证据选择器显示最近 200 条，更早的证据可从证据库建立关联后审核。

人工确认要求研究者、理由、本课题真实证据与当前版本号。论断内容、研究问题或证据关系变更后重新进入待审核状态。导出、图谱和迁移均读取同一投影；服务失败明确提示本地数据可能过期。迁移包恢复的本地 Claim 只作为草稿，不信任备份携带的最终审核状态。

项目整理同时锁定文件证据和 Claim，建立两者的撤销快照。ID 和人工状态保持不变，更新归属与版本；浏览器采用文件返回的 Claim 投影。发现迁移后新编辑时拒绝自动撤销，避免覆盖新数据。

## 文献互操作与筛选记录

支持常规 BibTeX 与 RIS 导入：先预览、主动勾选、确认后保存为未核验来源。保留作者、年份、期刊、卷期页码、DOI 与 URL，不导入摘要、附件或全文。支持两种格式导出及 JSON 备份往返；存在选择时导出所选，否则导出完整搜索／筛选范围。

一次导入最多 1000 条、2 MB；重复或缺少可追溯来源的文献明确跳过。不展开 BibTeX 宏、`#` 拼接、复杂 LaTeX 排版或远程附件。可将文献管理器导出的标准文件导入本工具；没有新增与第三方文献服务的在线同步连接。

可导出本地已保存候选集的 PRISMA 计数、逐条筛选状态和排除理由。报告明确范围：它不代表数据库完整检索或完整系统综述过程。

## 验证与性能门禁

`npm run check:performance` 使用仓库目录与合成证据测量搜索 P95，以及 1000／5000／20000 条证据建图中位数；门槛分别为 20 ms 和 180 ms。`npm run verify` 已接入此门禁。数字受机器、运行时和负载影响，不能替代真实宿主、数据库和网络的端到端测量。

`npm run test:browser` 验证首页按需加载、Claim 最近回答入口、确认门禁、迁移、窄屏，以及真实 IndexedDB 的 10000 条证据分页、跨页／跨筛选选择、范围外搜索和显式引用导入。浏览器宿主服务为测试桩；真实 DSH Desktop 最终导入与跨 Web 迁移仍按现有手工验收清单执行。

2026-10-03 本机验证结果（Node 26.10.0）：

- **历史快照（2026-10-03，非当前值）**：`npm run verify` 全部通过——555 项测试／76 个文件、4 个 DSH 基线。当前测试数与基线数见 README「兼容性与状态」及 [COMPATIBILITY.md](COMPATIBILITY.md)；语法、目录、文档、构建预算、覆盖率与合成性能门禁同样通过。
- 覆盖率：行 76.54%、分支 71.03%、函数 70.94%。客户端约 766 KB，gzip 约 228 KB，仍在既有预算内。
- 本次合成测量：目录搜索 P95 0.617 ms，2 万证据建图中位数 10.02 ms。运行间会有波动。
- 浏览器回归全部通过，运行错误 0；真实 IndexedDB 1 万条证据首个分页可见耗时约 254 ms，包含范围摘要读取，但不包含真实 DSH 后端与网络端到端耗时。
