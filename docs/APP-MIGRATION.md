# 本地备份与恢复

使用 DSH Desktop 的「科研工作台 → 时空囊」，可在换电脑、重装或重建客户端配置前保存完整研究资料，并在新配置中增量恢复。完整备份包含所有课题的证据、论断、资产关联、筛选账本、课题设置、知识节点与关系、灵感资产和最近研究运行。

## 导出和恢复

1. 在原配置打开「时空囊」，点击「导出备份」，保存 `research-kit-backup-*.json`。导出会先读取文件侧证据。文件侧不可读时会停止，避免生成不完整的备份。
2. 在目标配置安装并启用 Research Kit，从同一入口选择备份文件。系统会识别备份格式，校验完整备份的 SHA-256并展示各类数据的总数、预计新增数和本端已有数。选择和预览不会写入研究资料。
3. 点击「自动快照并恢复」。系统先将恢复前快照持久化到本机，写入成功后才增量恢复。可从同一入口下载最近一次快照，在独立配置中恢复到快照所含的数据。恢复按稳定 ID 补缺，已有记录保留。完成后刷新核对证据、资产和关联。关联任一端点缺失时会跳过并计数。
4. 恢复中断后，可重新选择同一文件、预览并继续恢复。文件侧已有同源来源会保留并提示。研究运行合并后超过 500 条时会在写入前停止。

备份含笔记、灵感资产和来源摘录，请存放在自己控制的位置。灵感资产恢复后保留稳定 ID 与内容，创建和使用时间可能以写入时刻重记。旧版导出的完整迁移包（`research-kit-app-transfer-*.json`）沿用同一格式，可直接选择恢复。证据库、灵感资产与知识星图单独导出的 JSON 也可从同一入口选择。

「资料库 → 最近删除」和待补记检索保留在发起操作的本机配置。换机前先恢复需要带走的证据和灵感，再在「科研账本与综述导出」确认检索已补记，然后导出时空囊。

## Desktop 验收

`npm run check:dsh-app -- /path/to/deepseek-harness` 检查宿主槽位和 Desktop 自定义协议转发。Desktop 复用同一份 `ui/client.js`，通过 `dsh-app://app/` 转发相对路径请求，应用内可用 `crypto.subtle` 校验备份。更新本地链接的插件后，刷新 App 以加载新版产物。

真实 Desktop 的增量恢复使用两个隔离配置验证，具体步骤见 [手工验收清单](MANUAL-QA.md)。2026-09-26 曾在真实 Desktop 核对入口、导出和预览。增量恢复和重复恢复已由隔离 Chromium 回归覆盖，真实 Desktop 的最终写入仍待验收。
